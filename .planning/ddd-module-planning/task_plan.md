# DDD 与六边形代码模块规划

## 目标

参考 `E:/CodingProgram/Java/Seeking-DDD-Parent` 的 Maven 模块和依赖组织，结合趣汇 R1-R4 产品、实体与系统架构，形成可落地的后端代码模块规划、依赖规则、包结构和分期拆分边界。

## 决策原则

- 参考项目只作为 DDD/六边形结构样本，不复制与趣汇无关的模块或过细启动模块。
- 领域模块不依赖 Web、MyBatis-Flex、RabbitMQ、Redis、MinIO 或具体外部供应商。
- R1 采用模块化单体装配，但代码边界必须支持 R2-R4 按域拆分部署。
- 模块数量以团队可维护性和真实复用为准，避免一个类一个 Maven 模块。

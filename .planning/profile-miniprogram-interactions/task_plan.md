# 个人资料与小程序交互

## 目标

完成签到状态反馈、移除社区通知入口、完善趣汇小程序探索抽屉与布局收藏模式，并将会员等级信息融入个人详情页，个人中心仅保留游客/VIP身份摘要。

## 阶段

- [completed] 1. 对齐产品与业务文档规则
- [completed] 2. 实现签到、社区通知和小程序抽屉交互
- [completed] 3. 重构个人详情与会员信息展示
- [completed] 4. 静态检查与浏览器验收

## 已确认规则

- 签到成功提示“签到成功，积分+n”，同一天按钮变为“今日已签到”。
- 社区右上角去除通知按钮，搜索入口保留。
- “探索更多”进入抽屉；小程序支持收藏/取消收藏，收藏项图标右上角显示星标。
- 长按小程序进入布局模式，右上角展示新增分类和保存；保存后按分类排序。
- 会员等级信息融入个人详情，个人中心个人信息区域仅显示游客或 VIP X。

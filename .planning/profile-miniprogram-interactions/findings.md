# 调研记录

## 当前实现

- `ProfilePage` 使用本地 `miniPrograms` 查询结果，但探索更多仅显示 toast；签到由父组件增加积分，页面没有“今日已签到”状态。
- `CommunityPage` 的 `PageHeader` action 同时渲染搜索和通知按钮。
- 个人信息卡与会员等级卡目前是两个相邻区块；需要保留会员操作但将等级信息并入详情卡。
- 小程序数据已有 `favorite`、`sortOrder`、使用频次和流量热度字段，可在原型层复制为可编辑本地布局。

## 浏览器验收 2026-08-10

- 签到按钮点击后显示“签到成功，积分+3”，随后变为禁用的“今日已签到”；积分和 VIP 计算同步变化。
- 个人详情展示“林知夏 → VIP 1 → 已认证”（认证状态开启时），等级权益、签到、邀请和 N/E 配额均在详情弹层内。
- “探索更多”打开右侧抽屉；已收藏项目显示取消收藏，未收藏项目显示收藏，状态切换可用。
- 社区顶部 DOM 仅保留搜索按钮，通知按钮已移除。

## 手机预览环境验收 2026-08-10

- 原型进程从仅监听 `::1:5173` 调整为 `0.0.0.0:5173`。
- 防火墙规则 `趣汇原型 5173 (Private)`：入站 TCP 5173，仅 Private Profile，Action Allow。
- `Invoke-WebRequest http://192.168.1.25:5173/` 返回 HTTP 200，`Test-NetConnection` 端口测试成功。

# 现状发现

- 新规则要求非单页原型按页面级状态或功能流程拆分，并先在交互说明中定义边界；不得只把所有内容继续放在一个页面文件。
- 当前 `App.tsx` 共 3504 行，包含 6 个一级页面、1 个独立搜索流程、共享卡片、静态数据和应用外壳。
- 项目未使用路由库，现有导航由 `PageKey` 状态驱动；本次应沿用这一约定。
- 工作树包含用户现有修改，拆分必须以当前文件内容为基线，不回退任何行为。
- 首轮机械拆分保持了 TypeScript 结构，但 Fast Refresh 规则要求数据/工具函数与 React 组件不能混在同一导出文件；共享层需要再分为纯数据模块和纯组件模块。
- 浏览器复核：拆分后的首页正常渲染，底部导航可进入社区；社区搜索、通知、发布、筛选和四类业务分段控件均保持可见。

# 拼车与线上开黑人数范围

## 目标
明确拼车和线上开黑不要求固定人数，统一使用最少人数与最多人数；同步原型卡片、发布字段、产品文档、业务规则和验收说明。

## 阶段
- [complete] 1. 现状定位与人数规则确认
- [complete] 2. 原型数据、卡片和发布表单修改
- [complete] 3. 产品与业务文档同步
- [complete] 4. lint、构建、关键词与截图复核

## 决策
- 拼车和线上开黑均使用 `minParticipants` 与 `maxParticipants`。
- 当前人数继续单独记录并用于进度条；卡片文案表达为“当前 / 最少-最多人”或“当前 / 最多人”。
- 最少人数达到后允许活动成立，最多人数达到后停止继续加入；不再使用固定目标人数作为唯一规则。
- 线下组队和拼单暂保留现有目标人数展示，避免扩大本轮范围。

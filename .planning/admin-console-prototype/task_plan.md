# 后台管理原型初步完善

## 目标

将已确认的 RBAC、三类管理员双端入口、区域范围和 R1-R4 分期设计同步到现有 shadcn/ui 原型，并初步完善后台工作台的信息架构、业务队列、审计、权限和区域管理交互。

## 阶段

- [x] 核对运营管理、权限、排期文档与现有管理页面，形成后台信息架构和角色差异清单。
- [x] 更新后台管理相关产品与交互说明，明确本轮原型范围和验收标准。
- [x] 完善独立 PC 后台导航、总览、业务队列、审计和权限页面内容与交互。
- [x] 完善区域管理员移动/PC 管理内容，并确保三类角色按 RBAC 范围显示差异。
- [x] 执行格式化、类型检查、lint、生产构建和 LOOP 浏览器验证，发现问题继续修复。
- [x] 回写截图、验证记录和最终交付说明。

## 决策基线

- 共用 `qh_user`，管理角色为附加 RBAC 授权，不建立独立管理员账户。
- 三类管理员均有移动端设置入口和独立 PC 管理入口；PC 端保留独立后台体验。
- `SYSTEM_ADMIN` 可查看权限授予和高风险审批；`OPERATION_ADMIN` 只能处理岗位业务队列；`REGION_ADMIN` 只能处理授权区域内容与工单。
- 后台原型只表达能力清单和失败关闭语义，不在客户端复制生产 Casbin 策略。
- 本轮使用现有 shadcn/ui 源码、预览入口、截图和交互文档，不创建 Pencil 产物。

## 错误记录

| 错误 | 尝试 | 处理 |
|---|---|---|
| 单个补丁同时删除并新增 `AdminConsolePage.tsx` 被工具拒绝 | 1 | 拆分为先删除旧文件、再新增同路径文件的两个补丁。 |
| 复用上轮浏览器标签页时返回 `Unknown tab` | 1 | 保留浏览器连接，丢弃失效标签页并新建验收标签页。 |
| 系统授权弹窗未关闭时切换区域管理员导致选择器无匹配 | 1 | 先关闭模态弹窗，再执行角色切换和区域工作台验证。 |
| 浏览器工具外部统计请求超时 | 1 | 继续完成本地交互，并单独读取页面日志区分工具遥测与原型错误。 |
| `fullPage` 截图仅返回空白背景 | 1 | 改用当前可视区域截图并显式写入工作区，复核成像后再纳入文档。 |

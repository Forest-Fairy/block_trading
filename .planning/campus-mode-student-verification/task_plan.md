# 学生认证与校园版

## 目标
新增仅本人可见的学生认证和可切换的校园版；校园版开启时，发帖默认仅同校可见，内容列表仅显示本人、关注用户或同校内容。

- [complete] 2. 校园身份数据、学生认证与校园版开关实现
- [complete] 3. 推荐、社区、搜索内容可见性过滤
- [complete] 4. 产品和业务文档同步
- [complete] 5. lint、构建、开关与列表截图复核

## 决策
- 演示账号已完成学生认证，所属“杭州大学”；认证状态只在“我的”页面显示。
- 校园版为全局偏好状态，默认关闭；开启时新发活动默认 `仅同校可见`。
- 内容筛选豁免本人发布和关注用户发布的活动；其他活动必须与当前校区一致。
- 商城商品不作为用户帖子，不受校园可见性规则影响。
- 学生认证与校园版区域位于偏好设置之后，退出登录固定为“我的”页面最下方的最后一项。

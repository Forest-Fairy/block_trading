# 发现记录

- 原型入口位于 `block_trading_docs/产品原型/shadcn-mobile`，使用 React、TypeScript、Vite、Tailwind 与 shadcn/ui。
- 悬浮助手主要实现位于 `src/components/floating-assistant.tsx`，已有菜单状态、拖拽/指针事件、嵌入与长按弹出逻辑。
- `src/App.tsx` 使用 `PageKey` 状态模拟路由，目前页面返回多由页面回调完成；需要补统一的移动端系统返回处理。
- 产品模块文档已有悬浮球交互基线，但仍写“按住 3 秒”，需改为 2 秒并补双击、点击菜单旋转与系统返回规则。
- 触觉和音效通过 `navigator.vibrate`、Web Audio API 提供，无需引入二进制媒体资源；不支持的设备静默降级。
- 悬浮态菜单已验证使用 135° 旋转、半透明毛玻璃底板和无文字星光图标；嵌入态菜单不带该底板。
- 嵌入音效已从三段提示音调整为单一连续蓄力音：三角波从 190Hz 升至 900Hz，在第一段旋转动画开始时启动；嵌入完成时立即截断，并播放一声确认音，取消归位时只停止蓄力音。
- 悬浮助手所有合成音效统一在输出增益处乘以 6，避免逐条修改预设而破坏相对响度关系。
- 今日首推的外层卡片保持无边框、无阴影；右侧信息列独立保留上、右、下三条边线，并通过 168px 固定高度和更大的标题、推荐原因、时间及操作间距避免信息拥挤。
- 所有面向用户的真实地点统一按“市区 · 街道”显示；学校、商品名称等并非地点的“城市”文本不作替换。
- 当前反馈 bug 的根因已定位：双击/长按弹出后，`endDockPointer` 会调用 `stopDockVibration`，该方法同时执行 `navigator.vibrate(0)`，立即取消弹出脉冲；长按期间的重复震动因此仍然有效。
- 当前悬浮球 JS 使用 `64px` 计算半径，而 CSS 实际尺寸为 `clamp(3.25rem, 14vw, 4rem)`，预置位为 `2.25rem`，两者尺寸来源不一致，导致对齐和嵌入尺寸偏差。

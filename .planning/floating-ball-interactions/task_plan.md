# 悬浮球交互调整计划

## 目标
实现悬浮球嵌入后的双击弹出、2 秒长按弹出、菜单 135° 展开/收起复原、触觉与音效反馈、悬浮态毛玻璃菜单，以及移动端分层返回行为，并同步更新业务开发文档。

## 阶段
- [x] 梳理现有悬浮球、页面状态和返回入口
- [x] 实现悬浮球交互、触觉、音效与视觉状态
- [x] 实现移动端系统返回分层处理
- [x] 更新业务开发文档与产品模块说明
- [x] 构建并执行原型验收
- [x] 修正嵌入尺寸与预置位几何对齐
- [x] 修正双击/长按弹出震动生命周期并确认浏览器可行性
- [x] 区分展开与收起菜单音效并更新文档

## 验证
- `npm run build`
- 打开原型目标页面，模拟菜单点击、双击、长按和返回行为，确认控制台无报错
- 连接 `http://localhost:5173/` 验证最新服务；Android Chromium 可调用 `navigator.vibrate`，iOS Safari 需降级。

## 错误记录

| 问题 | 处理 |
|---|---|
| 后台启动预览进程被本机策略拒绝 | 改用受控会话启动 Vite，实际服务运行于 `http://localhost:5174/`。 |
| 悬浮球初始可点击区域仅露出右侧一部分 | 浏览器验收改用可见区域坐标 380px 完成拖拽、菜单与收起验证。 |

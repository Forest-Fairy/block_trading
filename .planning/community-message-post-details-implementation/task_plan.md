# 社区消息帖子详情原型实施

## 目标

依据已对齐的规划文档完成社区首页、消息二级页/聊天和四类帖子详情的 shadcn/ui 原型调整。

## 阶段

- [completed] 1. 移除社区首页添加按钮并接入活动详情入口
- [completed] 2. 增加系统通知、业务通知二级页和私聊/群聊界面
- [completed] 3. 增加四类帖子详情页及跨页返回状态
- [completed] 4. 静态检查、构建和 `5173` 浏览器截图复核

## 验收记录

- 社区首页截图确认顶部只显示搜索和通知，无添加按钮。
- 线上开黑详情确认类型、平台、游戏类目、时长和最少/最多人数字段。
- 系统/业务通知二级页、群聊和私聊均已通过 DOM 交互检查。
- 私聊截图确认底部输入栏固定且不遮挡内容；控制台错误/警告为空。
- `npm run lint`、`npm run typecheck`、`npm run build`、`git diff --check` 均通过。

## 备注

- 用户启动的服务仅监听 IPv6 回环地址，浏览器验收使用等价入口 `http://[::1]:5173/`；产品文档记录 `127.0.0.1:5173` 并注明端口可变。

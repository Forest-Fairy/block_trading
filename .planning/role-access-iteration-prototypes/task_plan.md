# 角色权限与迭代原型

将游客、VIP 用户、校园模式、区域管理员和后台管理角色的产品规则统一为可追溯规划；以 RBAC 为权限模型，完成 R1-R4 可运行原型入口、阶段状态和关键交互。

## 决策基线

- 游客是唯一非 VIP 身份，仅可浏览被明确允许的系统信息。
- 所有已登录用户均为 VIP；VIP 等级是权益等级，不替代 RBAC。
- 区域管理员可从客户端设置进入区域管理界面，但每次访问仍受 RBAC 与区域范围校验。
- 运营管理员与系统管理员共用用户表和认证入口，通过后台管理界面访问系统管理能力。
- 权限模型使用 RBAC；生产鉴权模板采用 Casbin `RBAC with Domains`，以 `region_id` 为 domain；原型使用既有 shadcn/ui 后台布局表达入口和拒绝状态，不复制服务端策略判断。
- 游客保留推荐、社区、商城、消息和我的五入口预览，但不得收藏、下单、支付、发消息、创建草稿或读取真实订单；消息仅展示公开入会通知。
- 区域、运营和系统管理均提供移动端设置入口与移动端受控界面；运营和系统管理同时保留独立 PC Web 后台入口。
- 校园模式允许本人发布内容和已关注用户内容绕过同校区筛选，其余用户发布内容必须属于当前校区。
- 商城浏览、购物车、订单确认和基础支付状态表达前移到 R1；R2 在此基础上启用真实支付回调、库存预占、履约、退款和售后。

## 验收

- 文档定义账户类型、资格、角色、区域范围、访问路径和拒绝语义，并更新导航与枚举。
- R1-R4 均有可运行的原型入口和阶段状态说明；未开放能力可见但不可误操作。
- 游客、VIP、区域管理员、运营管理员、系统管理员的原型路径可演示，越权页面具有明确拒绝状态。
- 原型构建通过，浏览器验证关键路径且无控制台错误。
- LOOP 验证闭环不遗留已发现问题；每次修复均重新执行受影响路径的构建和浏览器验收。

## 错误记录

| 错误 | 尝试 | 处理 |
|---|---|---|
| PowerShell `New-Item` 不支持 `-LiteralPath` | 1 | 改用固定相对路径的 `-Path` 创建计划目录。 |
| 新增管理页未纳入助手来源页类型 | 1 | 将区域管理页和后台页的助手入口统一回退至推荐页，避免管理页被保存为详情返回页。 |
| 后台页签根容器横向排列 | 1 | 为后台 `Tabs` 显式添加 `flex-col`，使页签与内容保持上下布局。 |
| 移动端控制组件整体替换补丁被拒绝 | 1 | 按工具约束拆分为删除旧文件和新增同路径文件，替换已完成。 |
| lint 阻止在副作用中同步清理指针状态 | 1 | 改为由导航、角色切换和助手操作事件显式清理，避免额外渲染。 |
| 手机端预置位仍以页面透传的坐标初始化 | 1 | 改为在悬浮组件下一渲染帧读取预置位元素的实时 `DOMRect` 中心，并以手机壳矩形换算本地坐标。 |
| 悬浮球弹出动画影响矩形尺寸 | 1 | 所有落点和对齐计算改用 `offsetWidth`，避免 `transform: scale()` 造成中心偏移。 |
| 滚动后嵌入阶段固定限制顶部最小值为 52px | 1 | 移除顶部固定下限，仅保留底部导航边界，使预置位中心可在粘性标题栏中精确对齐。 |
| 滚动到日期不可见时标题与预置位被遮挡 | 1 | 将推荐页标题和预置位合为同一条粘性栏，滚动后保留可见的拖放目标。 |
| 后续停靠周期复用同一悬浮球节点，CSS 旋转动画未重新初始化 | 1 | 每次进入停靠流程递增动画 key，强制悬浮球节点创建新的动画周期。 |
| 从左侧预置位弹出后悬浮球被吸到左边缘 | 1 | 识别“从已停靠状态弹出且未移动”的释放，暂时回到右侧可操作边缘，离开预置位后恢复停靠检测。 |
| 弹出计时器在 releasePointer 清理时被取消，`is-popping` 长期覆盖停靠旋转动画 | 1 | 将弹出计时器提升为组件 ref，状态清理不再取消结束回调；停靠开始时显式清除弹出状态。 |
| 排期与测试文件首次核对使用了错误目录层级 | 1 | 先用 `rg --files` 定位到 `产品文档/项目文档` 下的实际路径，再确认大补丁已完整落盘。 |
| 商城原型合并补丁因商品详情尾部换行不匹配而被拒绝 | 1 | 确认补丁未部分应用后拆分为商品卡片、商城页和详情页三个小补丁。 |
| 浏览器首次页面读取调用了旧接口名 `dom` | 1 | 改用当前 `domSnapshot` 接口继续 LOOP，未改动页面状态。 |
| 浏览器工具外部统计请求超时 | 1 | 单独读取本地页面 `dev.logs()`，确认页面自身 error/warning 均为 0；不把工具遥测超时计入原型缺陷。 |

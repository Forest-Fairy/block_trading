# 调研发现

## 初始基线

- 正式规划已经定义系统管理员、运营管理员和区域管理员三类后台角色，并要求服务端按角色与区域范围逐请求校验。
- 现有 Vite/shadcn 原型通过 `App.tsx` 管理多页面状态；`viewerMode` 固定为 `member`，已具备学生认证、校园模式和偏好设置页面。
- 现有原型没有后台管理页、区域管理页、迭代版本入口或可切换的用户权限会话。
- R1-R4 排期已建立发布门禁；新增权限原型应按 R1 基础访问控制、R2 交易范围、R3 区域治理和 R4 风险治理逐期表达。
- 当前分期实体设计使用 `qh_admin_account` 承载管理员身份，与“共用同一个用户表”冲突；应改为 `qh_user` 作为所有已登录身份主体，角色授权直接关联 `user_id`。
- 已有 RBAC 枚举可复用：`SYSTEM_ADMIN`、`OPERATION_ADMIN`、`REGION_ADMIN`，并已定义资源、动作、风险等级和 `ALL/REGION/CAMPUS/SELF` 数据范围。
- 原型页面边界确定为：共享会话与迭代控制、客户端设置内的区域管理工作台、独立后台管理工作台；R1-R4 使用同一原型入口切换阶段状态。
- LOOP 不作为独立依赖或脚本存在；将作为最终验证闭环的执行规则，涵盖构建、角色路径、拒绝状态、布局和控制台检查，失败后修复并重验。
- 本轮补充：游客导航当前只保留推荐、社区、我的，须恢复商城与消息；消息页尚未接收访问主体，须增加游客默认入会提醒。设置抽屉只支持 `REGION_ADMIN`；移动端控制区被 `max-width: 30rem` 样式隐藏。悬浮球问题待从指针/容器坐标和路由切换状态定位。
- 预置位位于可滚动的 `.phone-content` 中，而悬浮球相对 `.phone-shell` 绝对定位。必须在浮层实际出现后的下一帧读取 `[data-assistant-dock]` 的 `getBoundingClientRect()`，以当前可视位置中心减去 `.phone-shell` 矩形换算；页面层保存或复用事件坐标会丢失滚动后的相对位置。
- 对动画元素不可用 `getBoundingClientRect().width` 推导布局半径，因为弹出阶段的 `transform: scale()` 会改变视觉矩形；需使用 `offsetWidth` 保持布局坐标一致。
- 预置位位于标题旁时，滚动后其中心可以进入原先 `52px` 顶部限制以内；该限制会让正确中心上移失败，表现为嵌入过程始终低于预置位。顶部边界应为 `0`，由底部导航约束可拖拽范围。
- 为使“日期不可见但标题和预置位仍可操作”的移动端验收场景成立，标题行与预置位必须同属粘性栏；否则目标与标题会同时滑出视口，无法验证滚动后的坐标换算。
- 重复嵌入不能只依赖 CSS class 的增删来重启动画；在停靠完成后悬浮球会保留组件生命周期，浏览器可能复用动画时间线。使用递增 `key` 重新挂载当前悬浮球，能稳定触发 approach、center、embed 三段动画。
- 从预置位弹出时，释放事件仍会走普通拖拽结束逻辑；若直接按预置位侧决定吸附边缘，左侧预置位会让悬浮球离开可操作区域。弹出未移动时应固定回右侧，等待用户主动拖离后再参与停靠候选判断。
- 弹出效果的局部 timeout 会在 `releasePointer` 更新时随 effect cleanup 被取消，导致 `popping` 状态一直为真；由于 `.is-popping .assistant-ball` 在停靠阶段 CSS 之后声明，它会覆盖后续旋转动画。计时器必须跨 release 状态更新存活，并在停靠开始时显式归零。
- 2026-08-16 审查决策确认：RBAC 逻辑设计需补充到物理 Oracle DDL；游客允许商城和消息预览但不得执行账户写操作；三类管理角色均有移动端设置入口，运营/系统管理员另保留独立 PC Web 后台；校园模式保留本人和关注用户例外；商城基础流程属于 R1；测试基线需增加上述边界。
- 当前商品卡片使用外层详情 `button` 包裹内层收藏 `Button`，运行时产生嵌套按钮控制台错误；需改为并列按钮结构并避免收藏事件触发详情跳转。
- 当前推荐页订单轮播对游客无条件显示真实订单样例，助手也未按游客态限制；应改为预览占位或登录提示，不允许游客进入写入草稿流程。
- 核心物理模型已经存在 `qh_operation_audit_log`，而分期治理逻辑模型另列 `qh_admin_audit_log`；本轮应统一复用前者并补足角色/区域/审批快照字段或使用其现有 JSON 快照，不再创建重复审计表。
- `ProductCard` 被商城等页面复用；应在共享组件内消除嵌套按钮，并通过可选收藏回调由页面按游客/VIP 决定“登录提示”或实际收藏反馈。
- 独立 PC 后台原型宜采用单独 `#pc-admin` 入口和桌面外壳，移动端设置仍进入手机壳内的受控管理页；两者复用同一角色/迭代会话与 `AdminConsolePage` 内容。
- RBAC 物理模型采用 `scope_key` 解决 Oracle 复合唯一键中的空值语义：`ALL`、`REGION:{id}`、`CAMPUS:{id}`、`SELF` 均可形成稳定的非空授权范围键。
- Casbin 表仅作为 Adapter 执行投影，授权事实仍由角色权限和用户角色范围表持有；这样可以在投影损坏时重建，并能对同步失败实施失败关闭。

# 迭代生命周期测试用例扩充

## 目标

依据 R1-R4 的业务场景、发布准入、架构验收和领域边界，补充可由 Agent 按 TDD 实现的功能测试用例，覆盖成功路径、权限边界、状态变化、异步失败、人工收口与发布回退。

## 阶段

- [x] 读取周期规划、架构验收、领域边界与现有用例
- [x] 按周期识别主链路、失败路径和发布风险缺口
- [x] 扩充 R1-R4 功能测试用例与周期执行规则
- [x] 校验用例 ID、模块引用、导航和 Maven Reactor

## 规则

- 测试用例只覆盖其所属周期已启用的能力；后续能力不成为前序构建前置。
- 每条关键发布能力至少有成功、拒绝或失败、可恢复/人工收口中的相应场景。
- 外部支付、物流和模型统一使用受控 Stub 或 Testcontainers，不使用生产凭据。

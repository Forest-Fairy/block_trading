# 首页社区商城消息交互调整

## 目标

对齐并实现通知入口、帖子详情、商品详情、返回按钮和订单业务通知的原型规则。

## 阶段

- [completed] 1. 将五项设计点写入产品/业务文档并刷新导航摘要
- [completed] 2. 调整首页、社区、商城和消息原型交互
- [completed] 3. 运行静态检查并用 5173 做浏览器截图复核

## 设计决策

- 推荐页与社区页的帖子卡片点击进入帖子详情；详情里的“去参与/申请加入/查看进度”只显示 toast，不改变路由或参与数据。
- 商城商品卡片进入独立商品详情页；商品卡片底部按钮统一显示“去看看”，暂不加购。
- 所有二级页面返回按钮通过 `PageHeader` 的左侧 action 统一表达，标题保持左对齐。
- 业务通知详情同时覆盖社区活动状态与商城订单状态。

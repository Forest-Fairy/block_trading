# 个人资料摘要与会员入口

## 目标

先将首页个人信息摘要、2×2 个人详情卡片、会员等级入口、内容分类标签，以及详情轮播满幅与内嵌指示器规则对齐至产品和业务文档；随后更新 shadcn 移动端原型并进行截图验收。

## 阶段

- [completed] 1. 对齐产品与业务规划文档
- [completed] 2. 更新首页摘要和个人详情交互
- [completed] 3. 更新会员等级页和帖子轮播视觉
- [completed] 4. 打开页面、模拟点击与控制台验收

## 已确认规则

- “我的”首页个人信息卡采用四行布局：头像跨前两行左列，右列依次为昵称/认证标签和个性签名，第三行定位与详情提示，第四行四类内容数量。
- 首页卡上下内容留白为 3px；前两行增加跨行签到列；学生认证标签仅在已认证时展示。
- 首页取消独立地址/点击提示行，地址移到头像下方，签到按钮右侧显示箭头。
- 签到按钮保持单行高度并增加宽度，完整兼容“今日已签到”。
- “更多趣汇小程序”首页去除提示信息，只展示已收藏项目；完整列表保留在抽屉。
- 首页定位使用图标加“杭州 · 西湖区”，与详情一致；详情头像移除固定 `lg` 尺寸约束，完整填满 88% 容器。
- 个人详情内容分类去除标题，四类使用单行 Tab 切换对应内容列表。
- 修复内容 Tab 横向滑动与帖子详情轮播横向手势。
- 轮播完整显示并以同图 `scale-100`、`brightness-90`、`saturate-100`、`blur-9xl`、`opacity-90` 底层与 `black/15` 覆盖形成左右毛玻璃过渡；前景主体保持清晰，仅在实际图片左右边缘以透明蒙版过渡；左右翻页按钮阻断指针事件进入轮播手势层，支持电脑端快速连击；小程序标题与收藏列表统一为标题/列表两行，无收藏仅保留标题；右上设置抽屉承载偏好设置、学生认证和校园版；首页卡补充用户名与定位/签名对齐。
- 未签到按钮为黄色，已签到按钮为绿色；首页与会员等级页状态色保持一致。
- 前端内容验收只需打开目标页面、模拟关键点击并确认浏览器控制台无报错，不要求截图；详情头像占左列宽度约 88%，用户名不显示 `@` 符号。
- 个人详情页仍展示可切换内容分类和对应内容列表；首页仅展示数量摘要。
- 个人详情信息卡使用 2×2 分区；首行左侧为头像、好评率、学生认证和定位，右侧依次为昵称、用户名、签名及已认证时的学生认证信息。
- 编辑模式显示头像蒙版“更换头像”，点击后打开图片文件选择；右列资料改为输入框。
- 卡片第二行提供可点击会员等级入口，展示邀请新人和全部等级权益。
- 详情轮播图片覆盖画布全高，顶部不留白；指示器置于图片内部，圆点为 1px 白色描边。

# 聊天与导航滚动交互计划

## 目标
优化用户消息首条提示样式，隐藏聊天页底部导航；实现详情进出滚动位置恢复、聊天默认置底，以及底部导航双击刷新当前页面并重置筛选；将原型布局由固定像素尺寸调整为相对尺寸，并固化尺寸规则。

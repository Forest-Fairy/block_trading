# 现状盘点

## 已确认的原型改动

- 页面代码已经按 `App.tsx`、页面模块、共享外壳和演示数据拆分，继续使用 `PageKey` 状态模拟路由。
- 社区分类统一为拼单、拼车、线下组队、线上开黑；列表无独立搜索框，顶部保留全局搜索和通知入口。
- 校园版由顶部状态栏右上角预览按钮切换，开启后社区标题与底部标签显示“校园”，并应用本人、关注用户、同校区可见规则。
- 学生认证仅本人可见，位于“我的”页面底部；认证完成后才能开启校园版；退出登录位于页面最底部。
- “更多趣汇小程序”位于兑换码上方，列表按性别适用、收藏、排序（空值靠后）、使用频次和流量热度处理，一分钟内复用查询结果，一分钟后刷新。
- 商城筛选使用右侧抽屉，商品分类移除“全部商品”，商品分类与商品状态都使用多选复选框。
- 拼车与线上开黑使用最少人数和最多人数，不以固定人数替代。

## 文档差异

- 社区文档仍把发布按钮写成首屏必备入口；这与当前“添加按钮去除”的后续界面调整要求需要在下一阶段明确，当前对齐阶段先记录现状与目标边界。
- 消息文档只有一级列表规则，缺少系统通知、业务通知二级页以及私聊/群聊界面说明。
- 社区文档已有“社区详情”概念，但没有把四种内容类型的详情字段、返回与主操作写成可验收的交互契约。
- 移动端产品设计文档仍使用 `4174` 作为预览入口，需更新为当前验收端口 `5173` 或注明端口可变。

## 后续界面调整边界

后续代码阶段将删除社区添加按钮，补充消息二级页面和聊天界面，并将四类社区卡片统一接入帖子详情页；这些属于本轮文档对齐后的实施内容，不在本阶段直接改代码。

## 浏览器复核记录

- `127.0.0.1:5173` 在当前环境仅监听 IPv6 回环地址，浏览器用 `http://[::1]:5173/` 可正常访问；用户原入口仍保留在文档中并注明端口可变。
- 首页截图/DOM 已确认扫一扫、搜索、通知、六类入口和四类业务文案正常显示。
- 社区截图/DOM 已确认顶部仅有搜索和通知、无添加图标；卡片详情入口可用。
- 线上开黑详情已确认展示游戏类目、平台、开始时间、时长、当前/最少/最多人数和主操作。
- 消息首页已确认系统通知、业务通知固定在用户消息之前，用户会话同时展示私聊和群聊入口。
- 系统通知二级页已确认安全、规则、公告标签和未读状态；业务通知二级页已确认成团、拼车、发货、开黑状态及关联详情入口。
- 群聊界面已确认返回、成员数、系统提示、消息气泡、附件、输入框和发送动作；发送一条测试消息后内容正常追加。
- 私聊界面已确认在线状态、私聊消息气泡、返回、附件和输入区均可见。
- 移动端截图复核确认私聊输入栏固定在底部且不遮挡消息，社区首页视觉上仅保留搜索/通知右上角按钮，没有添加按钮。

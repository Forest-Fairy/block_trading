# 当前原型与规划文档对齐

## 目标

盘点当前 shadcn/ui 原型已经落地的功能，将产品文档、业务开发文档和导航摘要补齐到与代码一致，为后续社区入口、消息二级页和帖子详情页改造建立可信基线。

## 阶段

- [completed] 1. 读取当前原型、产品文档和业务文档，记录差异
- [completed] 2. 更新产品文档正文与 navigator 摘要
- [completed] 3. 更新业务开发文档与首期规划验收项
- [completed] 4. 做文档一致性检查，并记录后续界面调整边界

## 约束与假设

- 仅对齐当前已存在代码和此前已确认的原型规则，不在本阶段新增界面代码。
- 原型入口以用户当前启动的 `http://127.0.0.1:5173/` 记录；开发服务器端口可按实际启动参数变化。
- 保留工作区已有未提交改动，不覆盖商城多选筛选和个人中心改动。

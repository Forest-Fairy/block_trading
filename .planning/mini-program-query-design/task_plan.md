# 趣汇小程序查询与偏好展示

## 目标
补充趣汇小程序列表的查询、筛选、排序和一分钟缓存规则；完善探索更多入口箭头，将系统设置改为偏好设置并移除用户编号展示。

## 阶段
- [complete] 1. 定位小程序原型与产品/业务文档
- [complete] 2. 列表查询缓存、性别适用和排序实现
- [complete] 3. 偏好设置文案与产品/业务文档同步
- [complete] 4. lint、构建、缓存逻辑和截图复核

## 决策
- 查询条件固定带 `onlyCurrentGender=true`，只保留全性别或当前用户性别适用的小程序。
- 单次缓存窗口为 60 秒；窗口内复用已查询列表，超过 60 秒才重新获取。
- 排序优先级：收藏在前、显式排序值升序且空值靠后、使用频次降序、流量热度降序。
- 原型用本地列表模拟一次列表接口响应，同时记录最近查询时间，便于验收缓存语义。

# 社区模块规划与原型优化

## 目标
将推荐内容列表改为触底自动加载，并优化社区模块的产品规划、业务规则、可运行 shadcn/ui 原型和截图验收。

## 阶段
- [complete] 1. 调研推荐触底加载与社区模块现状
- [complete] 2. 完善社区产品规划和业务开发文档
- [complete] 3. 实现推荐触底加载与社区原型优化
- [complete] 4. 构建、交互和移动端/桌面截图复核
- [complete] 5. 文档导航、验收结果与交付整理

## 决策
- 复用原型入口 `block_trading_docs/产品原型/shadcn-mobile/`。
- 推荐触底加载使用列表末端哨兵，禁止重复并发请求，筛选或刷新时重置分页。
- 社区模块延续现有 React、TypeScript、Tailwind CSS 和 shadcn/ui 组件体系。
- 分类命名基线统一为全部、拼单、拼车、线下组队、线上开黑；不再使用“凑伙”作为社区入口。

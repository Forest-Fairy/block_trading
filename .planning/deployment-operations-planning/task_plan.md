## 决策记录
- 本次以产品文档为基线，遵循 `项目文档 -> navigator.csv -> content.md` 的导航链。
- 仅做规划审查与文档回写，不实施部署脚本或后台功能。
- 日志策略需区分在线检索、文件滚动切片、月度归档、保留与清理，避免只写笼统的“日志管理”。
- “数据库按部署号指定”暂按部署批次标识选择目标数据库/Schema 与迁移基线理解，待从现有文档术语中校准。
- 用户补充确认所有 `quhui_` 模块名前缀均改为 `block_trading_`；只替换模块标识，不改“趣汇”品牌词或普通业务文本。
- 部署号定义为一次不可变部署执行的稳定标识，并引用受审批的部署清单；脚本不得直接接收 JDBC URL 或明文密钥。

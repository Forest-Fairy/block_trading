# 帖子领域建模与实体设计计划

## 目标
梳理拼单、拼车、线下组队、线上开黑与近邻互助的字段、类型、必填性和展示规则；完成可落地的数据库实体设计，并按最小必要字段调整发布表单与详情展示。

## 阶段
- [x] 定位现有帖子数据、详情、发布表单和产品规则
- [x] 输出五类帖子字段矩阵与通用/扩展实体模型
- [x] 编写 Oracle 数据库实体、枚举和字段长度/精度设计
- [x] 根据模型补齐原型创建输入与详情展示
- [x] 更新产品与业务文档并执行原型验证
- [x] 梳理跨模块实体边界与生命周期
- [x] 形成 Oracle 核心实体字段设计与关系说明
- [x] 生成无 SQL 外键的 Oracle 建表脚本并校验
- [x] 回写数据库设计索引与业务文档

## 验证
- 字段矩阵覆盖五类帖子，明确类型、必填性、校验与隐私策略。
- 实体设计满足公共帖子、类型扩展、媒体、参与和地点快照的持久化边界。
- 原型构建、lint 通过，并验证各类型的发布字段和详情展示。

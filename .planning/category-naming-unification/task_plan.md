# 社区分类命名统一

## 目标
将首页推荐与社区页面的娱乐/组队分类统一为“线下组队”和“线上开黑”，移除用户可见的“旅游”“游戏”“凑伙”分类命名，并同步产品与业务文档。

## 阶段
- [complete] 1. 现状定位与命名规则确认
- [complete] 2. 原型代码统一分类与筛选
- [complete] 3. 产品文档与业务文档同步
- [complete] 4. lint、构建与关键词检查

## 决策
- “线下组队”覆盖露营、徒步、羽毛球等线下活动。
- “线上开黑”覆盖线上游戏组队等在线活动。
- 拼单、拼车、商城等既有分类保持不变。
- 内部活动数据直接使用统一分类值，避免继续保留“凑伙”作为实现类型。

|---|---:|---|

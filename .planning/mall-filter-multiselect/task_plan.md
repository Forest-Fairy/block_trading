# 商城筛选多选改造

## 目标
删除商城筛选中的“全部商品”，将商品分类和商品状态改为语义化多选复选框，保留价格与排序条件。

## 阶段
- [complete] 1. 定位商城筛选状态与文档规则
- [complete] 2. 改造筛选状态模型和复选框交互
- [complete] 3. 同步产品与业务文档
- [in_progress] 4. lint、typecheck、build 与截图交互复核

## 决策
- 商品分类选项固定为实物商品、会员权益、服务产品，不提供“全部商品”。
- 商品分类与商品状态使用独立数组存储，可同时勾选多个条件，也允许全部不选。
- 排序仍保持单选按钮，价格仍使用上下限输入框。

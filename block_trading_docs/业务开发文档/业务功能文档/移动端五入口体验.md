# 业务功能文档：移动端五入口体验

## 对应需求

本功能承接“趣汇移动端首期规划”，把用户需求拆分为推荐分发、社区协作、商城交易、消息中心和个人中心五个实施模块。

## 功能关系

推荐负责流量分发，社区和商城负责业务转化，消息负责状态回流，我的负责个人业务归档和账户管理。五个模块共享登录状态、未读数量、深链路由和全局异常处理。

原型实现按推荐、搜索、社区、商城、消息、帖子详情和我的拆分页面模块；应用主文件只编排当前页面和跨页状态，共享外壳、卡片与演示数据独立复用。首期沿用 `PageKey` 状态导航，不额外引入路由框架；系统通知、业务通知、私聊和群聊作为消息模块内部二级状态。

## 系统悬浮助手与移动端返回

- 推荐页标题后的助手预置位嵌入后，单击打开四项快捷菜单；菜单项沿用悬浮助手的建帖、组队、求助和客服动作，菜单展开时按钮旋转并停留在 135°，收起时复原。
- 嵌入按钮支持两种弹出方式：持续按住 2 秒，或在 320ms 内连续双击。长按期间以短促循环振动保持反馈，成功弹出时再振动一次；长按、双击和弹出分别播放短提示音。设备不支持振动或 Web Audio 时静默降级。
- 普通悬浮球点击打开菜单时同样旋转并停留在 135°，收起时复原；点击菜单外区域、拖动或进入聊天会话时关闭菜单。
- 悬浮态展开菜单时，四项操作下方展示一层半透明毛玻璃背景板，增强与页面内容的层级区分；嵌入标题的菜单保持轻量展示，不增加该背景板。
- 悬浮状态仅展示助手图标，不显示“助手”文字；按钮保留可访问名称，避免视觉简化影响辅助技术识别。
- 菜单展开和收起均保持星光图标，不切换为关闭或加号图标；关闭动作由按钮状态和可访问名称提供反馈。
- 浮球进入预置位时，第一段旋转动画开始即播放单一连续的蓄力音效，并持续逐渐升调；嵌入完成瞬间截断蓄力音，紧接着播放一声清脆确认音并振动一次。取消归位仅停止蓄力音并清理后续时序，不播放确认音。
- 全部悬浮助手音效使用统一 6 倍音量系数，保留菜单、长按、双击、弹出、蓄力和完成确认音之间的相对响度关系。
- 移动端系统返回由原型 history 哨兵统一处理：搜索页返回推荐页，帖子/商品详情及助手聊天返回进入前页面，会员/偏好二级页返回“我的”，社区、商城、消息和“我的”一级面板返回推荐首页；推荐首页不拦截系统返回事件。

## 实施顺序

1. 建立底部导航、账户态和全局组件。
2. 完成推荐、社区、商城三个内容入口。
3. 完成消息状态回流和未读计算。
4. 完成个人中心、兑换码和系统设置。
5. 补齐异常状态、埋点、隐私和安全验收。

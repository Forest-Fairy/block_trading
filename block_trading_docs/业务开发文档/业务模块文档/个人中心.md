# 业务模块文档：个人中心

## 模块目标

按个人信息、更多趣汇小程序、兑换码、偏好设置的顺序组织账户和个人业务管理。

## 首期任务

- 建立头像、昵称、认证状态和资料编辑。
- 建立我发起的、我参与的、商城订单和收藏入口。
- 实现兑换码输入、校验、结果和历史记录。
- 实现账号安全、隐私、通知、通用、帮助和关于设置。
- 实现学生认证和校园版开关；认证信息仅当前用户可见，校园版开关依赖认证完成。
- 学生认证与校园版区域位于偏好设置之后，退出登录固定为个人中心最下方的最后一项。

## 验收重点

- 未登录状态不展示伪造的业务数据。
- 兑换失败保留原输入并给出明确恢复动作。
- 退出登录与账号注销明确分离。
- 学生认证成功后才可开启校园版，开启状态和“仅同校可见”说明清晰可见。

# 业务模块文档：消息中心

## 模块目标

按系统通知、业务通知和用户消息组织全部信息，并统一计算未读状态。

## 首期任务

- 固定系统通知和业务通知的前两项位置。
- 建立用户会话、置顶、已读、发送失败和消息设置。
- 支持商品、活动和不可伪造的业务状态消息卡片。
- 实现举报、拉黑、删除会话和风险限制提示。
- 完善系统通知和业务通知二级列表页，保留返回、已读和关联业务详情动作。
- 支持用户私聊与活动群聊原型，区分自己、对方和系统状态消息，并覆盖发送中、失败重试、离线缓存和群聊受限状态。

## 验收重点

- 消息页顺序始终符合产品要求。
- 进入分类不自动误清全部未读。
- 离线恢复后消息发送状态能够收敛。
- 系统通知详情能够按优先级和时间倒序展示安全、公告、规则和审核内容。
- 业务通知详情能够展示成团、拼车确认、组队提醒，以及商品下单、支付、发货、签收、退款和售后状态，并能回到关联帖子或订单。
- 私聊和群聊的消息气泡、成员信息、输入区、发送失败与受限状态表达清晰，敏感联系方式不直接公开。

# 趣汇枚举值字典

## 使用规则

- 本文是数据库设计中 `VARCHAR2` 枚举和 `CHAR(1)` 布尔字段的统一允许值来源。数据库、Java 枚举、接口 Schema、事件 Schema 和测试 Fixture 必须使用同一英文存储码；中文仅作为展示名称。
- 存储码统一使用大写 `UPPER_SNAKE_CASE`，布尔值只使用 `Y/N`。未在本文登记的值不得直接写库；新增或废弃枚举前先更新本文、所属实体设计、接口文档和测试。
- `target_type`、`subject_type`、`related_type` 等多态对象字段只能使用“对象类型”词典中的值；某张表只能采用与其职责相关的子集。
- 状态不得通过覆盖历史掩盖迁移；帖子、订单、支付、履约、审核、权益和账号处置均保留专用流水或不可变事实。

## 通用枚举

| 枚举族 | 允许值 | 适用字段与说明 |
|---|---|---|
| 布尔标识 | `Y`、`N` | 所有语义为布尔的 `CHAR(1)` 字段，包括 `*_flag`、`*_enabled`、`deleted`、`urgent`、`is_cover`、`requires_confirmation`、`label_visible`；`Y` 为是/启用，`N` 为否/停用。 |
| 对象类型 | `USER`、`DEVICE`、`ADDRESS`、`POST`、`POST_COMMENT`、`MESSAGE`、`MEDIA`、`PRODUCT`、`USER_LISTING`、`ORDER`、`PAYMENT`、`DELIVERY`、`AFTER_SALE`、`REVIEW`、`REPORT`、`REGION`、`DATA_ASSET`、`MINI_PROGRAM`、`MEMBERSHIP`、`CONFIG`、`ROLE`、`PERMISSION`、`AUDIT` | `target_type`、`subject_type`、`owner_type`、`related_type` 的允许全集；具体字段按专用行采用子集。 |
| 操作主体 | `USER`、`SYSTEM`、`ADMIN`、`WORKER`、`PROVIDER` | `operator_type`、`reported_by_type`、`submitted_by_type`、`collected_by_type`。 |
| 媒体类型 | `IMAGE`、`VIDEO`、`VOICE`、`FILE` | 帖子、商品、刊登和聊天附件；各实体按实际支持能力采用子集。 |
| 优先级 | `LOW`、`NORMAL`、`HIGH`、`URGENT` | 审核、工单、物流异常；不得与需求排期 `T1/T2/T3` 混用。 |
| 风险等级 | `LOW`、`MEDIUM`、`HIGH`、`CRITICAL` | `risk_level`、`severity`；`CRITICAL` 必须进入人工加急或事件响应。 |
| 通用审批状态 | `PENDING`、`APPROVED`、`REJECTED`、`EXPIRED`、`CANCELLED` | `qh_admin_approval.status`。 |
| 通用申诉状态 | `SUBMITTED`、`IN_REVIEW`、`UPHELD`、`OVERTURNED`、`REJECTED`、`WITHDRAWN` | 审核、评价、封禁和侵权申诉。 |
| 异步任务状态 | `PENDING`、`PROCESSING`、`SUCCEEDED`、`FAILED`、`DEAD_LETTER`、`CANCELLED` | 可见性失效、通知或其他可重试任务；Outbox 发布使用下文专用状态。 |
| 配置版本状态 | `DRAFT`、`PENDING_APPROVAL`、`ACTIVE`、`SUSPENDED`、`RETIRED`、`REJECTED` | 区域策略、规则集、模型、政策版本和服务路由。 |
| 审核/控制结论 | `ALLOW`、`REJECT`、`REQUIRE_MODIFICATION`、`TEMPORARY_RESTRICT`、`UNPUBLISH`、`RESTORE`、`MANUAL_REVIEW` | 审核阶段、商品合规和人工覆盖；模型只能写建议，不能独立写最终处罚。 |

## 状态迁移原则

1. 帖子、订单、支付、履约、审核和账号处置只允许领域状态机定义的迁移；接口传入任意其他码一律拒绝。
2. 终态不能被迟到事件覆盖。已退款不能回到已支付，已交付不能被早期物流节点回退，已关闭审核案不能被模型结果重新打开。
3. `FAILED`、`REJECTED`、`CANCELLED`、`REVOKED` 和 `EXPIRED` 必须保留原因、操作主体和发生时间；允许恢复的流程通过新事件或显式恢复状态推进。
4. 字典中的允许值是逻辑约束；Oracle `CHECK`、Java 枚举、接口校验和测试必须在对应周期实现时同步落地。

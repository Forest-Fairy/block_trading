# 推荐

## 页面目标

推荐页是移动端默认首页，通过统一信息流分发社区内容、商城商品和未读通知。页面优先帮助用户发现可立即参与或购买的内容，而不是展示纯宣传信息。

## 页面结构

1. 顶部栏：趣汇品牌、当前城市、搜索入口和通知入口。
2. 未读摘要：仅在存在高优先级未读消息时出现，展示类型、摘要和未读数。
3. 兴趣筛选：关注、附近、拼单、拼车、凑伙、商城。
4. 综合信息流：社区卡片、商城卡片和通知卡片按策略混排。
5. 底部导航：固定五个一级入口。

## 内容卡片

### 社区卡片

- 显示购物拼单、出行拼车或娱乐凑伙类型。
- 显示标题、封面、发起人、地点、时间、当前人数和目标人数。
- 主操作为“去参与”；已参与时显示“查看进度”。
- 已满员、已截止或已取消时保留卡片但降低操作优先级。

### 商城卡片

- 明确显示“趣汇自营”标识。
- 显示产品图、名称、核心卖点、价格和库存状态。
- 点击卡片进入商品详情；快捷操作加入购物车。

### 通知卡片

- 只插入与用户当前业务直接相关的高优先级消息。
- 支持成团、行程变更、活动即将开始、订单发货等类型。
- 点击后进入对应业务详情，不仅进入消息列表。

## 推荐策略

首期采用可解释规则排序：用户关注和已参与业务更新优先，其次是附近且即将截止的社区内容，再次是匹配分类偏好的商城商品。连续三条内容不得全部来自同一业务类型。

用户可执行“不感兴趣、减少此类内容、举报、分享”。负反馈立即从当前信息流隐藏，并记录到后续推荐规则。

## 交互说明

- 下拉刷新生成新一批内容，顶部给出新增数量反馈。
- 上滑分页加载，加载失败时在列表末尾局部重试。
- 点击搜索可跨社区和商城检索，结果页按类型分组。
- 点击城市切换位置；拒绝定位时允许手动选择城市。
- 从详情返回恢复卡片位置、筛选项和滚动偏移。

## 页面状态

| 状态 | 页面表现 |
|---|---|
| 首次使用 | 展示热门和附近内容，不强制兴趣问卷 |
| 无推荐 | 展示热门社区分类与商城新品入口 |
| 离线 | 展示最近缓存内容并标记更新时间 |
| 未登录 | 正常浏览，参与和购买时触发登录 |
| 内容失效 | 卡片标记结束原因，允许查看历史详情 |

## 数据指标

- 卡片曝光、点击、停留和负反馈。
- 推荐到参团、购买或消息已读的转化率。
- 各内容类型曝光占比和用户返回率。

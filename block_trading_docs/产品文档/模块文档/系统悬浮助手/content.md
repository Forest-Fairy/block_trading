# 系统悬浮助手

## 模块定位

系统悬浮助手是移动端跨页面的统一轻入口，承载建帖、近邻求助和在线客服。它不替代社区首页的信息架构，也不在社区页面新增添加按钮；所有建帖路径都由此入口进入。

## 悬浮球与菜单

- 悬浮球默认位于页面右边缘的中下部。拖动过程实时跟随手指，松手后才吸附到左或右边缘；顶部不能进入状态栏，底部最大位置为底部导航上边框减去悬浮球半径，因此最多只有半个球沉入导航栏视觉层。
- 悬浮球吸附后 2.6 秒无操作自动向边界外收起三分之二，仅露出三分之一。每次新的按下或拖动都会立即清理此前的收起计时，避免拖动中途被自动收回。收起态首次点击只恢复完整球体并重置计时；若球体沉入底部导航，同时上移到导航栏上沿之上。第二次点击才打开菜单；系统“减少动态效果”开启时不播放滑入滑出动画。
- 底部导航始终拥有更高层级，避免浮球覆盖导航按钮。存在未完成草稿时，悬浮球使用金黄色发光边框；展开菜单后，存在草稿的功能项显示金黄色圆点。
- 点击完整悬浮球展开四项菜单：发起拼拼贴、我要组队、发起求助、在线客服。浮球在右侧时菜单向左展开，在左侧时向右展开；当浮球靠近顶部时菜单顶部对齐，当浮球靠近底部时菜单底部与底部导航上沿对齐，避免任何菜单项被遮挡。菜单采用淡入，选择任一功能后立即淡出并打开沉浸式聊天。
- 悬浮态展开菜单时，四项操作整体置于半透明毛玻璃背景板上，背景板带浅边框和阴影；标题嵌入态菜单不增加该背景板，保持标题区轻量。
- 悬浮状态的球体仅显示助手图标，不显示“助手”文字；按钮的可访问名称保持完整，菜单项继续显示文字标签。
- 菜单展开与收起均保持星光图标，不切换为关闭或加号图标；关闭状态继续由可访问名称表达。
- 悬浮助手的菜单、长按、双击、弹出、蓄力和完成确认音统一使用 6 倍音量系数，保持不同反馈之间的相对响度关系。
- “我的 → 通用设置”提供“悬浮球音效”和“悬浮球震动”两个独立开关，默认开启并即时生效；关闭音效不影响震动，关闭震动不影响音效。不支持 Web Audio 或 Web Vibration API 的设备按能力静默降级。
- 点击菜单外的任意页面区域、滚动页面、拖动浮球或进入任一沉浸式流程时关闭菜单；菜单外点击只关闭菜单，不改变浮球位置和收起状态。所有可点击区域不小于 44px，并提供名称可访问标签。
- 推荐页标题“趣汇”后方设置仅用于原型的预置位。未嵌入时展示虚线圆形框，作为标题行内的 `relative` 子项参与正常布局，不使用 `absolute` 或 `fixed` 定位；它随推荐页标题及内容流向上滚出视图，向下回滚时随标题重新出现，预置位不可见时不接受归位。浮球与预置位按真实 DOM 尺寸计算圆心对齐，避免响应式尺寸造成左上角偏移。浮球中心进入可见预置位的 56px 容错范围后，须连续 0.5 秒未移动才开始归位。归位总时长为 2.4 秒、共旋转三圈，每圈 0.8 秒：第一圈转至 360 度，缩小至约 84%，同时移动到当前停留位置与预置位中心之间的中点；第二圈转至 720 度，继续缩小至约 68%，同时移动到预置位中心；第三圈转至 1080 度，继续缩小约 18%，随后在预置位中心恢复为预置位直径并嵌入。第一段旋转动画开始即播放单一连续的蓄力音效：使用正弦波，音高逐渐抬升，音量按四分之一正弦曲线从静音增长至峰值；嵌入完成瞬间在峰值处直接截断，不做衰减，紧接着播放一声清脆确认音并提供轻触觉反馈。取消归位只停止蓄力音并清理后续动画时序，不播放完成确认音。完成后隐藏、预置位变为助手按钮，形成嵌入效果。嵌入后单击助手按钮打开快捷菜单，按钮旋转并停留在 135°；菜单收起时平滑复原。连续双击，或按住助手按钮 2 秒，按钮外圈显示加载进度，完成后浮球以弹簧效果从预置位位置弹出并立即接管当前手指继续跟随，松手后才结束拖动，按钮恢复为虚线圆形框。长按期间持续提供短促震动和每声 0.1 秒的“嘟”提示音，停止按住立即停止该提示；长按成功、双击和弹出各播放对应短提示音，弹出时额外轻触觉反馈一次。设备不支持 Web Audio 或振动时保持功能可用并静默降级。手指重新拖动嵌入中的浮球时，立即取消归位动画并由手指在当前位置继续接管，松手后再按普通拖动规则吸附。弹出后必须先拖离预置位容错区，才能再次触发嵌入；拖动离开容错范围或提前松手长按均取消计时。
- 移动端 Web 的预置按钮与浮球均禁用触摸平移手势。浮球在 `pointerdown` 后捕获该指针，并直接处理其 `pointermove`、`pointerup`、`pointercancel` 与捕获丢失事件；窗口事件仅作兜底。每次新的按下均重置上一轮指针状态，确保连续拖动可用。归位阶段仅页面其他区域的滚动会取消归位并吸附右侧；从浮球开始的移动必须由手指继续接管。长按弹出后由预置按钮持续转发同一 `pointerId` 的移动坐标；仅该手指的实际松开事件能结束拖动并触发边缘吸附。
- 预置位的 0.5 秒静止判断、2.4 秒嵌入进度与三圈旋转缩小动画均可中断：期间拖动浮球、用户主动滚动页面，或点击底部导航任一入口，立即取消嵌入、清理计时，并让浮球按当前位置直接吸附到右侧；自动滚动等程序行为不应中断嵌入，滚动和导航原有行为继续执行。

## 建帖流程

| 菜单动作 | 建帖类型 | 机器人首轮引导 | 必填补充方向 |
|---|---|---|---|
| 发起拼拼贴 | 购物拼单、出行拼车 | 一次说清想拼的商品/路线、时间、人数、地点和预算 | 商品与交付，或路线、座位与费用 |
| 我要组队 | 线下组队、线上开黑 | 一次说清活动、时间、地点或平台、人数和要求 | 费用/取消规则，线上最少与最多人数 |
| 发起求助 | 普通求助、紧急求助 | 一次说清需要什么帮助、时间、地点、报酬和最晚响应时间 | 时效性、使用时段、报酬与隐私范围 |

1. 用户先在菜单选择大类，再在聊天上下文中选择明确类型，例如“发起拼拼贴 -> 拼单/拼车”；明确类型写入草稿上下文，随后才请求自然语言描述，不再重复询问类型。选择后提供“返回类型选择”操作。
2. 后端表单构建智能体根据明确类型的字段 schema 解析文本，并以 SSE 增量返回 `{ "form": {}, "force": [] }`、`missingRequiredFields`、`assistantMessage` 与 `confidence`。`form` 仅为建议回填值；`force` 只包含用户在本轮输入中明确要求修改的字段名。
3. 前端只对未手动编辑的字段应用 `form`。当字段已由用户填写且不在 `force` 中时，显示“是否采用”而非覆盖；在 `force` 中时才可覆盖，并保留变更记录。每一轮只追问 1 至 3 个最影响发布的缺失字段。
4. 标准聊天头部并列“返回”和“手动填写”按钮，输入栏左侧不再放编辑按钮。用户在本次会话实际修改类型、输入内容、表单字段或图片后点击返回时，弹窗只询问“是否保存草稿”，并提供“暂不保存”和“保存草稿”；未编辑时直接返回。
5. 字段校验完成后展示“预览帖子”按钮，点击后进入手动填写页，而不是直接发布。手动填写页顶部提供多图上传栏，第一张图标记为封面；无图片时展示浅色随机底色与随机帖子标题，标题使用白色描边。
6. 预览提交前仍执行字段校验、敏感内容治理和场景安全规则，成功后进入社区既有审核流程；模型没有发布权限。

## 求助与客服

- 普通求助按既有会员月度配额校验；紧急求助先展示“如遇人身危险请优先拨打当地紧急电话”的明确提示，再允许创建，避免把平台聊天表达为紧急救援能力。
- 在线客服跳转到独立客服聊天会话，支持文本和语音输入。语音按钮按住开始录音，向上滑动取消，正常松开后转写到输入框供用户确认，不自动发送。
- 建帖对话也复用文本和语音输入；语音仅是输入方式，不影响字段来源、校验或审计标识。

## 原型交互说明

- 原型用固定时序模拟后端流式回填：发送自然语言后，以 `{ form, force }` 逐项回填草稿，随后机器人展示下一轮缺失字段问题与“是否采用”状态。
- 原型覆盖右侧展开菜单、左侧展开菜单、2.6 秒自动收起、实时拖动、顶部/底部菜单对齐、草稿金色状态、推荐页预置位嵌入与单击菜单/双击或 2 秒长按弹出、长按与弹出触感、可配置音效和震动开关、每声 0.1 秒的长按提示音、蓄力音效、菜单展开 135°/收起复原、移动端系统返回、客服按住语音、智能建帖、预览手动填写、多图封面与取消创建。

## 验收标准

1. 右、左边缘各自菜单朝页面内侧展开，且菜单不会遮挡浮球露出的可点击区域；靠近顶部/底部时菜单对应对齐并完整可见。
2. 停留 2.6 秒后浮球只露出约三分之一；拖动过程实时跟手，松手会吸附到最近侧，底部最多沉入导航栏半径高度。
3. 有未完成草稿时球体为金黄色发光边框，打开菜单后相应功能项显示圆点。
4. 菜单选择后先淡出，再进入对应聊天；建帖经过明确类型选择和上下文回退后，聊天底部始终有文本输入与语音按钮。
5. 一段自然语言输入能以 `{ form, force }` 逐项回填草稿、提示字段采用与追问缺失必填项；手动填写、保存草稿确认和取消创建均可达。
6. 建帖完成后可进入预览手动填写，多图上传时第一张明确为封面；无图时浅色随机背景与白色描边标题可见。
7. 390×844px 下菜单、聊天输入栏、悬浮球与底部导航无不合理重叠，紧急求助安全提示可见。
8. 推荐页预置位的浮球容错停留、3 秒嵌入环形进度、三圈连续缩小且最终恢复预置位直径并保持圆心对齐、嵌入按钮单击菜单、双击弹出与 2 秒长按弹出均可完成；菜单展开时按钮停留在 135°、收起及自动收起时复原并播放对应音效，长按持续震动并播放每声 0.1 秒的“嘟”提示音，弹出和嵌入完成各震动一次，音效和震动可在通用设置独立开关，单一蓄力音效从旋转动画开始升调，嵌入完成时截断并播放一次确认音，提前移出或松手时只停止蓄力音。
9. 移动端系统返回在非首页按页面层级返回，一级面板回到推荐首页，推荐首页不拦截系统返回事件。

# 社区

## 页面目标

社区页承载围绕共同需求建立关系的社交功能，首期包含购物拼单、出行拼车、线下组队和线上开黑。用户可以浏览、筛选、发布、参与、分享和管理活动。

社区页不是传统帖子广场，首要目标是帮助用户判断“是否同路、是否同趣、是否来得及参与”，并完成参与或发起。纯内容讨论与泛兴趣动态不进入首期社区列表。

## 核心用户任务

1. 查看可参与、即将截止或与兴趣匹配的活动。
2. 按拼单、拼车、线下组队、线上开黑切换分类，并从右侧抽屉选择业务筛选条件。
3. 在列表卡片上判断时间、地点、费用、人数缺口、发起人可信度和参与方式。
4. 查看自己已参与或发起的活动，并识别待处理状态。
5. 选择业务类型并保存发布草稿，后续补齐差异字段后提交审核。
6. 从详情返回后恢复视图、筛选、已加载页数和滚动位置。

## 页面结构

1. 顶部栏：页面标题、当前城市语境、全局搜索和带未读数量的通知入口。
2. 视图切换：“发现”和“我参与的”。
3. 业务分类：全部、拼单、拼车、线下组队、线上开黑，使用唯一一组分段控件，避免重复入口。
4. 筛选与排序从右侧抽屉打开：拼单支持价格/数量/收货地点距离，拼车支持上车地点/出行时间，线下组队支持目的地距离/人均消费，线上开黑支持开始时间/时长/游戏类目。
5. 社区列表：统一卡片骨架，根据业务类型展示差异字段。
6. 分页反馈：触底加载、加载中、加载失败重试和暂无更多。
7. 发布入口：发现/我参与的切换栏右侧加号打开发布 Sheet，并根据当前分类预选类型。

## 发现视图

### 搜索、分类与筛选

- 社区列表不设置独立搜索框；右上角搜索图标进入全局独立搜索页。
- 分类只保留一组“全部、拼单、拼车、线下组队、线上开黑”分段控件。切换分类后重置分页并保留通用筛选。
- “5km 内”“今天”“仅看已认证”为可独立开关的筛选条件，选中状态同时通过颜色和文字表达。
- 排序使用菜单或分段控件，支持“综合推荐、距离最近、即将截止”。排序变化后从第一页重新加载。
- 筛选结果为空时保留当前条件，并提供清除筛选或发布同类活动两个动作。

### 校园版可见性

- 学生认证仅当前用户可见；认证后可在偏好设置中切换校园版。
- 校园版开启时，社区发现列表和搜索列表除本人发布、关注用户发布外，仅展示当前校区内容。
- 发布 Sheet 明确展示帖子默认范围：校园版开启时为“仅同校可见”，关闭时为“公开可见”。
- 校园版开启时，页面标题和底部导航中的“社区”统一显示为“校园”；顶部状态栏右侧的预览按钮开启后标识当前为已认证学生用户。

### 列表头

- 标题根据视图显示“可参与活动”或“我的社区进度”。
- 辅助信息显示匹配数量和当前城市，不使用营销性描述。
- 排序操作与结果数量同一层级，避免在列表上方堆叠多组面板。

## 社区列表与触底加载

- 首屏加载 4 条，列表末端哨兵进入视口后自动请求下一页，不使用“加载更多”按钮。
- 触底加载立即显示轻量加载状态；同一列表同一时间只允许一个分页请求，重复触底不得并发。
- 请求成功后在原列表尾部追加，不重排已曝光内容，不改变当前滚动位置。
- 切换视图、分类、筛选、排序或提交搜索时取消旧请求，从第一页重新加载。
- 加载失败时在列表末端显示失败原因和“重试”，已加载内容保持可用。
- 最后一页显示“已看完当前结果”，提示不占用卡片样式，不重复触发观察器。
- 从详情返回时恢复已加载页数、内容顺序、筛选和滚动位置；缓存过期时原地提示刷新。

## 社区卡片

- 公共字段：业务类型、标题、推荐或匹配原因、时间、地点或线上属性、当前人数与人数范围、截止时间、发起人认证状态。
- 购物拼单突出单人价格、目标人数、截止时间和交付方式。
- 出行拼车突出起点、终点、出发时间、当前人数、最少同行人数、最多座位和费用方式。
- 线下组队突出活动主题、地点、集合时间、人数缺口和参与要求；线上开黑突出活动主题、平台、开局时间、当前人数、最少参与人数、最多人数和参与要求。
- 主操作统一为“去参与”；需要审核时显示“申请加入”，已参与时显示“查看进度”。
- 卡片不公开手机号、车牌号、群号或精确家庭地址；敏感信息只在确认参与后按权限展示。

## 我参与的视图

- 汇总我发起、已参与、待审核和已结束的活动，默认按待处理优先、时间倒序排列。
- 每条记录显示身份、活动状态和下一步动作，例如补充资料、确认申请、查看进度或再次发起。
- 待审核、费用变化、时间变化和活动取消必须有明确状态说明，不依赖消息红点表达。
- 无参与记录时提供“去发现”和“发起活动”两个入口。

## 分类设计

### 购物拼单

适用于共同购买、批量优惠或分摊运费。卡片展示商品或服务、单人价格、目标人数、当前人数、截止时间和交付方式。

发布时填写标题、商品来源、目标人数、价格说明、截止时间、交付方式、退款规则和参与须知。

### 出行拼车

适用于共同路线和时间的出行。卡片展示出发地、目的地、出发时间、当前人数、最少同行人数、最多座位、费用方式和发起人认证状态。

发布时填写出发地、目的地、时间窗口、车辆或乘客身份、最少同行人数、最多座位、费用、行李限制和联系规则。精确联系方式仅对已确认成员开放。

### 线下组队与线上开黑

线下组队适用于露营、徒步、羽毛球等线下活动；线上开黑适用于游戏组队、桌游和电竞活动。卡片展示活动类型、线上或地点、开始时间、目标人数、已有人数和参与要求；线上开黑额外展示最少参与人数和最多人数。

发布时选择线下组队或线上开黑，填写主题、时间、地点或平台、人数规则、成员要求、费用和取消规则；线上开黑必须填写最少参与人数与最多人数。

## 社区详情

- 头部展示类型、标题、状态和分享操作。
- 核心信息区展示时间、地点、费用、人数进度和截止时间。
- 发起人区展示头像、认证信息、历史完成率和举报入口。
- 成员区展示已加入成员及剩余名额；隐私场景只显示脱敏头像。
- 说明区展示详细描述、参与要求和取消规则。
- 底部固定主操作：立即参与、申请加入、管理活动或查看结果。

## 状态模型

```text
草稿 → 审核中 → 招募中 → 已达标 → 进行中 → 已完成
                  ├──────→ 已满员
                  ├──────→ 已取消
                  └──────→ 已超时
```

出行和线下组队类内容可配置为“申请加入”，由发起人确认；购物拼单默认即时加入。涉及支付时，参与记录和支付记录分开表达。

- 拼车和线上开黑不使用固定人数：达到最少人数即满足成立条件，达到最多人数后停止继续加入。

## 发布流程

1. 从视图切换栏右侧发布按钮进入发布 Sheet，先选择拼单、拼车、线下组队或线上开黑。
2. 填写公共字段：标题、时间、地点或线上方式、人数规则、参与说明。
3. 根据类型补充商品与交付、路线与座位、活动主题与成员要求等差异字段。
4. 实时保存草稿；关闭 Sheet 不丢失已填写内容。
5. 提交前检查必填项、敏感信息和安全提示，提交后进入审核中。
6. 原型首期模拟“保存为草稿”，成功后在社区页显示可继续编辑的反馈。

## 安全与治理

- 出行和线下组队活动必须提供举报、拉黑和紧急联系人提示。
- 不在公开页面展示手机号、车牌号和精确家庭地址。
- 对高风险词、外部交易引导和异常频率发布进行审核。
- 用户退出、活动取消和费用变化必须产生业务通知。

## 页面状态

| 状态 | 页面表现 |
|---|---|
| 无内容 | 提供切换分类、扩大范围和发起活动三个动作 |
| 人数已满 | 达到最多人数时主按钮显示已满员，可允许候补 |
| 已超时 | 展示未达标原因和退款或关闭进度 |
| 审核中 | 仅发起人可见，显示预计处理时间 |
| 被拒绝 | 展示可修改项和重新提交入口 |

## 原型交互说明

- “发现 / 我参与的”切换对应发现列表和个人进度列表。
- 业务分类、筛选条件和排序会共同计算当前结果，并重置触底分页；搜索统一进入独立搜索页。
- 列表首屏展示 4 条，继续向下滚动后自动追加下一页，并显示加载中和暂无更多反馈。
- 点击卡片主操作模拟参与状态变化；已参与内容进入“我参与的”。
- 点击发布按钮打开 Sheet，选择类型并填写公共字段后可保存草稿。
- 线下与出行类内容持续显示认证和隐私提示，不在列表暴露联系方式。
- 校园版开启时，列表保留本人和关注用户内容，并对其他用户内容应用同校区过滤；发布 Sheet 展示“仅同校可见”默认范围。

## 验收标准

1. 首屏能识别社区或校园标题、全局搜索、带未读数的通知、发布入口、发现/我参与的、四类分段控件、筛选排序和活动列表，列表区域不出现独立搜索框。
2. 页面没有重复的分类入口，分类、筛选和排序选中状态清晰且不会互相覆盖。
3. 社区卡片无需进入详情即可判断类型、时间、地点、人数进度、截止与认证状态。
4. 列表触底自动加载，加载过程中不重复请求，追加后不重置滚动位置，最后一页有明确反馈。
5. 切换分类、筛选、排序和视图会重置分页并更新匹配数量；全局搜索进入独立搜索页。
6. 发布 Sheet 可选择类型、填写公共字段并保存草稿，关闭后反馈可理解。
7. 390×844px 下文字、分段控件、卡片和底部导航不重叠，最后一项不被遮挡。
8. 桌面预览保持手机容器完整，页面无横向溢出，图片和状态表达正常。
9. `npm run lint` 与 `npm run build` 通过，默认、筛选、发布和触底状态截图复核通过。
10. 学生认证信息仅认证用户本人可见；认证后可开启校园版，开启后列表按本人/关注用户/同校区规则过滤，发布默认范围清晰可见。

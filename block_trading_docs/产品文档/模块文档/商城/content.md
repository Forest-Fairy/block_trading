# 商城

## 页面目标

商城是趣汇公司自营产品的购买入口。首期不开放第三方商户入驻，所有商品必须明确自营身份、售后主体和履约规则。

## 页面结构

1. 顶部栏：搜索、订单和购物车入口。
2. 运营位：当期主推产品或活动，必须可关闭且不遮挡浏览。
3. 分类入口：实物商品、会员权益、服务产品和限时新品。
4. 推荐商品：双列或横向列表，显示图片、名称、价格和状态。
5. 品牌与服务说明：自营、正品、售后和配送承诺。

## 商品卡片

- 商品主图应完整展示实际产品，不使用与商品无关的氛围图。
- 展示商品名、短卖点、当前价格、划线价条件和自营标识。
- 库存紧张、售罄、预售和限购必须明确表达。
- 点击卡片主体进入商品详情页；卡片底部按钮统一显示“去看看”，暂不直接添加购物车。

## 筛选抽屉

- 商品分类只提供“实物商品、会员权益、服务产品”，不提供“全部商品”选项；未勾选分类等同于不限制分类。
- 商品分类使用复选框，可同时选择多个分类，再次点击已选分类可取消。
- 商品状态提供“全新、二手、有货、包邮”，使用复选框并支持多选组合。
- 最低价格和最高价格继续使用输入框；综合、销量、价格和距离排序保持单选。
- 分类与状态的选中状态同时通过复选框、边框和文字颜色表达，不只依赖颜色。

## 原型交互说明

- 点击商城列表标题右侧筛选按钮打开右侧抽屉。
- 分类和状态可跨分组组合选择；点击“应用筛选”关闭抽屉并保留已选状态。
- 页面实现：`src/pages/MallPage.tsx`；当前验收入口：`http://127.0.0.1:5173/`（端口以实际启动参数为准）。

## 验收标准

1. 商品分类中不显示“全部商品”。
2. 商品分类与商品状态均使用语义化复选框，且至少能分别同时选中两项。
3. 商品卡片点击进入商品详情，底部按钮显示“去看看”而不是“添加购物车”。
4. 商品详情返回按钮位于左上角，返回后筛选和列表位置不丢失。
5. 价格输入和排序条件不受多选改造影响，抽屉在 390×844px 下无横向溢出。

## 商品详情

- 图片、商品名称、价格、规格、库存、配送范围和售后政策。
- 详情页支持从商城卡片进入，展示商品订单关联、配送和售后说明；原型阶段不直接执行加购或购买。
- 规格变化必须同步更新价格、库存和预计发货时间。
- 底部固定客服、购物车、加入购物车和立即购买。
- 对会员或兑换码关联商品明确权益有效期和使用限制。

## 交易流程

```text
浏览商品 → 选择规格 → 确认订单 → 支付 → 待发货 → 待收货 → 已完成
                                             └──────→ 售后中
```

支付失败保留待支付订单并给出剩余支付时间。库存只在订单确认阶段短时锁定，超时后释放。

## 页面状态

| 状态 | 页面表现 |
|---|---|
| 售罄 | 保留商品信息，主操作禁用，可订阅补货通知 |
| 超出配送范围 | 说明限制并允许更换地址 |
| 价格变化 | 结算前再次确认，不静默替换价格 |
| 支付失败 | 保留订单和支付信息，允许重试或更换方式 |
| 售后中 | 在订单和消息页同步展示处理进度 |

## 数据指标

- 商品曝光、详情访问、加购、结算和支付转化。
- 分类、搜索词、退款原因和补货订阅量。

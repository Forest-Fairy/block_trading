# 移动端交互规范

## 视觉方向

趣汇的视觉关键词为可信、活跃、协作和清晰。界面使用中性浅色背景、深色正文、绿色主操作、暖黄色强调和珊瑚色提醒，避免单一色系占满页面。

| Token | 建议值 | 用途 |
|---|---|---|
| Background | `#F6F7F3` | 页面背景 |
| Surface | `#FFFFFF` | 列表和内容表面 |
| Foreground | `#1B1D1B` | 主文本 |
| Muted | `#6C726F` | 次级文本 |
| Border | `#E0E4DE` | 分隔和边框 |
| Primary | `#1F7658` | 主操作和当前导航 |
| Accent | `#F2B84B` | 人数进度和重点提示 |
| Coral | `#E9654B` | 截止、紧迫和高关注提示 |
| Info | `#3C6FA8` | 系统信息 |

## 排版与间距

- 中文使用 Noto Sans SC，英文和数字使用 Inter。
- 页面标题、区块标题、正文和辅助文本分别以 `1.5rem`、`1.125rem`、`0.875rem`、`0.75rem` 为基线。
- 间距以 `0.25rem` 网格递增，常用值为 `0.5rem`、`0.75rem`、`1rem`、`1.5rem`。
- 卡片圆角不超过 `0.5rem`，按钮和输入框使用 `0.5rem` 圆角。
- 字间距固定为 0，不按屏幕宽度缩放字号。

## 核心组件

- 顶部栏、底部五栏导航、搜索框、分类分段控件。
- 社区活动卡片、商城商品卡片、通知摘要卡片。
- 人数进度、状态徽标、头像组、价格和截止时间。
- 主按钮、次按钮和图标按钮；社区首页不展示浮动或添加发布按钮。
- 骨架屏、空状态、错误提示、确认弹窗和轻量反馈。
- 系统悬浮助手：入口采用 `clamp(3.25rem, 14vw, 4rem)` 的圆形尺寸、镜像快捷菜单、沉浸式聊天与手动表单切换；它是系统入口，不作为社区页内的发布按钮。

原型使用 React、TypeScript、Tailwind CSS 和 shadcn/ui 实现。基础控件优先复用 shadcn/ui 的 Button、Card、Badge、Avatar、Tabs、Dialog、Sheet、Input、ScrollArea 和 Separator；图标统一使用 Lucide。图标按钮使用熟悉符号，并通过 `aria-label` 或 Tooltip 提供可访问名称。

- 顶部状态栏右侧临时提供校园版预览切换按钮；开启后模拟当前用户为已认证学生用户并显示激活状态，关闭后恢复普通模式。
- 校园版开启时，社区页面标题和底部导航标签同步显示为“校园”，不得出现“社区/校园”混用。

## 页面尺寸

移动端基准画板为 390×844，仅用于验收参考。实现时，页面区块、卡片、列表项、媒体缩略图、分类栏和面板必须使用比例、网格、`clamp()`、视口约束或 `aspect-ratio` 适配可用空间；不得以固定像素宽高作为普通布局基线。内容区应考虑顶部状态栏和底部安全区；列表页面底部预留导航高度，固定控件不得遮挡最后一项内容。

允许保留绝对值的范围限于 1px 边框或描边、阴影扩散、像素对齐的微标、图标视觉尺寸和最小可触达尺寸。每项例外需在交互说明和交付说明中注明位置与原因。

### 当前例外清单

| 位置 | 保留内容 | 原因 |
|---|---|---|
| `src/index.css` | 1px/1.5px/2px 边框、描边和 1px 分隔线 | 保证细线在不同设备像素栅格上稳定显示，不参与区域尺寸计算。 |
| `src/index.css` | `box-shadow` 的扩散、偏移和毛玻璃 `blur` 值 | 这些值只描述阴影或视觉效果，不是布局宽高；调整为比例会改变阴影层级和质感。 |
| `src/index.css`、`src/components/ui/*` | `outline`/focus ring 的像素对齐值、Tabs 的 `100%-1px` 边界补偿 | 用于键盘焦点和控件边界对齐，不改变页面内容尺寸。 |
| `src/pages/*`、`src/components/*` | Lucide 图标的 `size` 参数 | Lucide API 需要稳定的图标视觉尺寸，图标本身不承担页面布局宽高。 |

除上述例外外，当前原型的页面容器、卡片、媒体缩略图、分类栏、面板、文字字号和间距均使用相对单位、容器百分比、`clamp()`、视口约束或 `aspect-ratio`。

## 交互反馈

- 点击反馈在 100ms 内出现，网络操作立即进入加载状态。
- 二级页面的返回按钮统一位于左上角；右上角仅承载当前页面的分享、更多、筛选等工具操作。
- 列表局部更新不得重置整个页面滚动位置。
- 支付、退出活动、删除、拉黑和注销需要确认。
- 成功反馈说明下一步去向；失败反馈说明原因和恢复动作。
- 倒计时在不足一小时时提高视觉优先级，但不使用持续闪烁。
- 悬浮助手拖放结束后在 4 秒无操作时自动收起三分之二，仅保留三分之一可点区域；点击露出区域立即完整展开。拖放只允许吸附左右边缘，纵向位置必须保留状态栏与底部安全区，允许其下半部分位于底部导航栏视觉后方但不得越出屏幕。

## 原型覆盖要求

高保真原型至少覆盖五个一级页面的默认状态，并补充以下关键状态：可收起/恢复的推荐今日首推、社区筛选、五类帖子详情（类型标签、标题、覆盖式可滑动多图轮播、发起人备注/进度、详细信息、提示和带举报菜单的嵌套回复留言列表）、近邻互助游客受限详情、个人详情只读/编辑/头像添加状态、六个偏好设置二级页、商城购物车状态、消息通知二级页、私聊/群聊、兑换码输入弹层。

原型目录固定为 `block_trading_docs/产品原型/shadcn-mobile/`。原型需要能够通过本地开发服务器运行；前端内容验收只需打开目标页面、模拟关键点击，并确认浏览器控制台没有报错，不要求截图验证。
- “我的”个人信息摘要使用约 `0.625rem` 内边距和约 `0.5rem` 的头像/业务快捷入口间距，避免首屏上下留白过大。
- 手机局域网预览使用原型开发服务器的 `5173` 端口，服务监听局域网网卡而不是仅监听回环地址。

本模块为交互规范，不定义运行时功能接口。

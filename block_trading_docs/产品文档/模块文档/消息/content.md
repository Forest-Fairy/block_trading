# 消息

## 页面目标

消息页按重要性和业务属性组织信息。“全部”先展示系统通知分类行、业务通知分类行，再展示用户消息；选择“系统”或“业务”分类后，在当前列表直接展示对应完整通知内容。用户无需进入多个业务页面即可了解平台状态、交易进度和沟通更新。

## 页面结构

1. 顶部栏：标题、全部已读和消息设置。
2. 全部分类：展示系统通知分类行与业务通知分类行，点击分类行切换到对应顶部分类。
3. 系统/业务分类：显示对应标题及完整通知列表；系统承载账号、安全、审核、规则和平台公告，业务承载社区活动、商城订单、支付、退款和履约状态。
4. 用户消息：分组标题下方先展示“陌生人消息可在我的 · 隐私设置中关闭”的说明，再展示私信、活动成员沟通和客服会话列表；该说明不得置于历史会话列表末尾。

## 通知优先级

| 级别 | 示例 | 表达方式 |
|---|---|---|
| 紧急 | 账号风险、支付异常、行程取消 | 顶部标识、强提醒、不可批量忽略 |
| 重要 | 成团、发货、退款结果、申请审核 | 未读徽标和业务状态色 |
| 普通 | 活动提醒、互动、运营公告 | 常规列表样式 |

## 列表规则

- 系统通知和业务通知在首页直接展示完整列表，保留时间、状态标签、未读状态和关联详情动作。
- 用户会话按最新有效消息排序，置顶会话优先。
- 被撤回、屏蔽或风控拦截的内容使用明确占位说明。
- “全部已读”不影响要求用户确认的安全和协议类消息。

## 会话能力

- 支持文本、图片、商品卡片、社区活动卡片和系统提示。
- 支持举报、拉黑、删除会话和关闭提醒。
- 线下活动会话不得自动暴露手机号、地址等隐私信息。
- 订单和活动状态使用不可伪造的系统消息样式，与普通用户文本区分。

## 通知内容与聊天界面

### 系统通知

- 消息首页直接显示系统通知列表；每条通知展示标题、时间、正文摘要、优先级和已读状态。
- 安全与协议类通知保留确认或查看规则动作，不因“全部已读”而跳过必要确认。

### 业务通知

- 消息首页直接显示业务通知列表，按业务时间倒序展示拼单成团、拼车确认、组队提醒，以及商品下单、支付、发货、签收、退款和售后状态。
- 业务通知必须带关联对象和状态标签；存在关联帖子或商品订单时提供“查看详情”动作，进入后可通过左上角返回按钮回到消息详情列表。

### 私聊与群聊

- 用户消息列表进入一对一私聊或活动群聊；顶部显示返回、对象名称、在线状态或群成员数以及更多操作。
- 会话正文区区分自己和对方的消息气泡，系统状态消息单独使用状态样式；群聊消息展示发送者昵称和头像。
- 底部输入区固定包含文本输入、发送按钮和附件入口；发送中、失败、重试、禁言/拉黑和离线缓存状态均需可见。
- 线下活动聊天不直接公开手机号、精确地址和其他敏感联系方式，必要信息通过业务卡片或确认成员后展示。

## 未读规则

底部消息徽标为三类未读总和；超过 99 显示 `99+`。进入分类不等于全部已读，只有内容进入可视区域或用户执行全部已读后才更新状态。

## 实时通信与恢复

私聊、活动群聊和需要即时表现的通知由 Netty WebSocket Gateway 接入；Gateway 仅负责连接、认证、心跳、限流、协议编解码、摘流通知和消息分发，不直接保存消息或改变会话状态。会话、成员、消息、确认和已读事实均由 engagement 服务持久化，发送成功以服务端返回 `ACCEPTED` 为准，不以客户端已写入 Socket 为准。

实时协议命令的允许值为：`AUTH`（认证/续期）、`PING`（心跳）、`SEND`（发送）、`ACK`（确认接收）、`READ`（更新已读）、`RESUME`（按游标补拉）、`DRAIN`（服务端要求重连）、`ERROR`（失败）。客户端发送 `SEND` 必须携带稳定 `client_message_id`；服务端为每个会话分配单调递增 `message_seq`，客户端断线、跨节点投递失败或服务发布摘流后使用最后确认游标发送 `RESUME`，按序补拉未确认消息。客户端在收到 `DRAIN` 后停止发起新业务消息，随机退避后建立新连接并恢复；未完成发送按相同 `client_message_id` 重试，不得制造重复消息。

发送/投递结果允许值为：`ACCEPTED`（已持久化）、`DELIVERED`（已写入当前目标连接）、`ACKED`（目标连接确认）、`OFFLINE`（待补拉）、`REJECTED`（权限、频控、内容或会话限制拒绝）。`ACCEPTED`、`DELIVERED`、`ACKED` 依次表达不同事实，UI 不得将前一状态展示为后一状态；被拉黑、禁言、封禁或审核拦截时，服务端拒绝发送、投递和补拉，并保留页面要求的受限说明。

## 页面状态

| 状态 | 页面表现 |
|---|---|
| 无消息 | 保留系统和业务通知入口，用户消息区展示空状态 |
| 消息发送失败 | 原位置显示失败标识并支持重试 |
| 会话受限 | 说明禁言、拉黑或风险限制及申诉方式 |
| 离线 | 展示缓存消息，恢复网络后同步发送状态 |
| 通知详情为空 | 保留返回入口和分类说明，展示空状态 |
| 群聊受限 | 显示禁言、已解散或权限不足原因，并保留历史消息 |

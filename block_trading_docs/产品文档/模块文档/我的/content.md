# 我的

## 页面目标

“我的”集中展示个人身份、业务状态、更多趣汇小程序、兑换码和偏好设置。信息顺序固定为个人信息区域、更多趣汇小程序、兑换码入口、偏好设置区域。

## 页面结构

### 个人信息区域

- 顶部展示头像、昵称、账号标识、认证状态和资料编辑入口。
- 在同一区域下方展示我发起的、我参与的、商城订单和收藏四个业务快捷入口。
- 未登录时展示默认头像和登录按钮，不展示伪造的业务数量。

### 兑换码

- 作为个人信息后的独立入口，展示图标、标题和简短状态提示。
- 支持扫码或手动输入兑换码。
- 提交前去除首尾空格并统一大小写规则，但保留原始输入用于错误提示。
- 兑换结果必须说明获得内容、有效期、使用入口和失败原因。

### 系统设置

设置项按以下顺序组织：账号与安全、隐私设置、消息通知、通用设置、帮助与客服、关于趣汇。退出登录位于页面底部，与普通设置项保持视觉距离。

### 学生认证与校园版

- 学生认证与校园版区域位于偏好设置之后；退出登录固定为“我的”页面最下方的最后一项。
- 学生认证使用学校和学号完成身份核验，认证状态及学校信息仅当前用户可见。
- 认证完成后展示校园版开关；关闭时不改变现有内容可见性，开启时新帖子默认仅同校可见。
- 校园版开启后，推荐、搜索和社区活动列表仅保留本人发布、关注用户发布或当前校区内容；商城商品和系统通知保持正常展示。

## 业务快捷入口

| 入口 | 内容 |
|---|---|
| 我发起的 | 草稿、审核中、招募中、已结束的社区活动 |
| 我参与的 | 已申请、已加入、进行中和历史活动 |
| 商城订单 | 待支付、待发货、待收货和售后 |
| 收藏 | 社区内容和商城商品，按类型筛选 |

## 兑换码状态

| 状态 | 页面表现 |
|---|---|
| 可兑换 | 显示确认兑换和权益说明 |
| 已使用 | 显示使用时间和对应账户 |
| 已过期 | 显示有效期和不可使用原因 |
| 不适用 | 说明适用产品、地区或用户条件 |
| 网络失败 | 保留输入内容并允许重试 |

## 隐私与安全

- 账号安全页展示登录设备、密码或验证方式和账号注销入口。
- 隐私页控制位置、推荐个性化、陌生人消息和活动资料可见性。
- 敏感操作需要二次验证；注销账号不可与退出登录混淆。

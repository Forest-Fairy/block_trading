# 我的

## 页面目标

“我的”集中展示个人身份、业务状态、更多趣汇小程序和兑换码。偏好设置统一由右上角设置入口打开；完整个人资料和会员权益进入个人详情页。

## 页面结构

### 个人信息区域

- 首页不展示“我的”标题，也不使用 PageHeader，避免标题行空白。提示语“趣汇，让生活充满品味”和设置按钮使用手工顶部工具区：提示语为主色、`14px`、半粗样式，设置按钮固定为 `1.65rem`（`2.75rem × 60%`）并沿顶部右侧对齐。头像嵌入透明的资料 Card 结构容器：Card 顶部内边距固定为 `1.35rem`，作为紧凑虚拟首行；头像为直径 `4.7rem`（半径 `2.35rem`）的 Card 子项，在实际资料首行底部对齐，并向上溢入虚拟首行。点击资料卡头像打开图片预览；编辑弹窗中的头像同样可点击预览当前草稿图片，不触发文件选择。外层 Card 不绘制背景、边框或圆角；独立的浅绿圆角边框表面从实际资料首行（虚拟首行之后）开始渲染。资料卡实际首行中列为用户昵称和用户名、右列为编辑图标，三者与头像底部对齐；第二行左列独立展示好评率、带定位图标的“杭州 · 西湖区”及已认证时的“杭州大学 · 西湖校区”标签，右侧展示个性签名且其文本顶部与标签文字顶部对齐，首、二行之间不绘制横向分隔线；第三行为会员等级栏。卡片资料栅格不额外设置横向内边距，编辑按钮右边距与会员等级栏同为 `0.75rem`。认证标签不在昵称旁或用户名旁展示 VIP 标签。用户昵称、用户名和个性签名超出可用宽度时不使用省略号，改为仅在溢出时横向滚动完整内容。取消独立地址/点击提示行和内容分类数量栏；编辑图标打开资料编辑弹窗，个人信息卡不再提供详情跳转。
- 个人信息摘要采用紧凑卡片间距（内边距约 `0.625rem`、统计区上间距约 `0.5rem`），减少头像区与业务快捷入口之间的上下留白。
- 未登录时展示默认头像和登录按钮，不展示伪造的业务数量。

### 会员等级与近邻互助配额

- 注册用户默认 VIP 1，等级由历史累计获得积分决定；当前积分用于权益，消费不影响等级。
- 会员等级页展示当前积分、累计获得积分、每日签到奖励、已邀请人数/99 人月上限，以及近邻互助的普通求助和紧急求助当月剩余配额；“我的”首页资料卡下方使用浅绿色整行会员等级样式，在其右侧加入签到按钮，并在最右侧完整显示“查看等级权益 >”进入等级详情。
- VIP 1 至 VIP 6 的累计获得积分门槛分别为 0、6、36、82、132、216；每日签到积分分别为 3、2、1、1、1、1。会员权益页仅展示 VIP 2 至 VIP 6 的累计获得积分门槛，VIP 1 不展示“累计获得积分满 0 分”。
- 邀请奖励在受邀者完成注册后结算，每位 5 分，每自然月最多 99 位；近邻互助的普通求助和紧急求助配额按自然月重置、不结转，草稿与审核失败不占用。
- 签到成功后即时提示“签到成功，积分+n”，当日按钮变为“今日已签到”；再次点击保留可反馈状态并提示“今日已签到”，避免重复领取。
- 游客状态提供“登录后解锁附近互助完整内容”的引导，不展示会员积分、发帖配额或伪造个人业务数据。

### 首页资料编辑

- “我的”个人信息卡不再跳转独立个人详情页；仅右上编辑图标打开资料编辑对话框。对话框使用头像预览与“更换头像”按钮，并按“用户昵称、用户名、个性签名”的标题加输入框结构编辑资料。
- 点击“更换头像”打开图片文件选择框；取消不保存，保存时校验昵称与用户名非空、昵称不超过 20 字、用户名不超过 30 字、个性签名不超过 80 字，保存后立即回写首页摘要并显示“个人资料已保存”。
- 会员等级页的未签到按钮使用金黄色背景和白色文字；完成签到后切换为绿色背景和白色文字。
- “我的”首页在兑换码下方展示“我发起的 n、我参与的 n、评论评价 n、商城订单 n、我的收藏 n、趣汇空间 n”单行 Tab，不显示“内容分类”标题，其中趣汇空间固定为最后一项。单项宽度控制为视口约可见 3.5 项，明确提示可左右拖动；Tab 不换行并支持左右滑动浏览，选中态清晰高亮，切换下方对应内容列表。
- 好评率按审核有效且评分不低于 4 分的用户评价占审核有效用户评价总数计算，无有效评价时不展示比例；资料摘要只读取聚合缓存。“评论评价”展示与当前用户相关的用户评价，每条评价必须关联订单项或社区参与记录。商品评价只评价商品，不计入用户好评率。

### 兑换码

- 作为个人信息摘要后的独立入口，展示图标、标题和简短状态提示。
- “我的”首页“更多趣汇小程序”恢复为无外层卡片的简洁区块，按标题行、收藏列表行顺序展示；标题下方不展示查询时间、性别适用等提示信息，横向列表仅展示已收藏项目。无收藏项目时不显示空状态或额外列表行，仅保留标题行；完整可用项目只在“探索更多”抽屉展示。
- 点击“探索更多 >”打开右侧抽屉；每个小程序均可收藏或取消收藏，已收藏图标右上角显示星标。
- 长按小程序进入布局模式，右上角提供“新增分类”和“保存”；可将小程序移动到分类并调整分类内顺序，保存后按分类顺序展示全部小程序。
- 默认分组可配置为 `{ group: "default", label: "默认分组", labelVisible: false, apps: ["market", "gaming"] }` 形式。
- 支持扫码或手动输入兑换码。
- 提交前去除首尾空格并统一大小写规则，但保留原始输入用于错误提示。
- 兑换结果必须说明获得内容、有效期、使用入口和失败原因。

### 偏好设置与二级页

“我的”右上角提供设置图标，点击从右侧打开设置面板。设置项按以下顺序组织：账号与安全、隐私设置、消息通知、通用设置、帮助与客服、关于趣汇；其后在同一面板展示学生认证与校园版卡片、当前 RBAC 角色对应的管理入口及独立的退出登录操作。每项进入独立二级页，左上角返回，变更即时保存并提供反馈；主页面不再直接展示偏好设置、学生认证、校园版、管理入口或退出登录操作。

| 二级页 | 主要内容 | 关键动作 |
|---|---|---|
| 账号与安全 | 绑定手机、登录设备、密码与账号注销 | 设备下线、修改密码、进入注销说明 |
| 隐私设置 | 个人资料可见性、位置精度、个性化推荐、陌生人消息 | 开关或选项选择后即时反馈 |
| 消息通知 | 系统、业务、私聊/群聊通知及免打扰时段 | 分类开关、设置开始/结束时间 |
| 通用设置 | 主题、语言、缓存和网络图片策略 | 单选主题、清理缓存、保存偏好 |
| 帮助与客服 | 常见问题、意见反馈、在线客服 | 展开问答、提交反馈、发起客服会话 |
| 关于趣汇 | 版本、更新检查、服务协议和隐私政策 | 检查更新、打开说明页 |

### 学生认证与校园版

- 学生认证与校园版卡片位于设置面板的偏好设置入口之后，退出登录位于该面板底部并与普通设置项保持视觉距离；“我的”主页面不再展示上述操作。
- 学生认证使用学校和学号完成身份核验，认证状态及学校信息仅当前用户可见。
- 认证完成后展示校园版开关；关闭时不改变现有内容可见性，开启时新帖子默认仅同校可见。
- 校园版开启后，推荐、搜索和社区活动列表仅保留本人发布、关注用户发布或当前校区内容；商城商品和系统通知保持正常展示。

### 管理入口

- 所有登录用户都是 VIP；游客只显示公开内容与登录引导。VIP 等级、学生认证和校园模式均不自动授予管理权限。
- 当服务端确认当前 `qh_user` 具有有效 `REGION_ADMIN` 授权且区域范围未过期时，设置面板在学生认证卡片之后显示“区域管理”入口。入口打开受限区域管理工作台，并传入当前 `region_id`、角色、权限快照和请求关联。
- 区域管理工作台仅展示授权城市、校区或服务区域的审核队列、公告、客服工单、区域能力开关和风险上报。缺失角色、权限、区域范围或二次验证时，入口或目标接口必须返回明确拒绝状态；客户端不以本地角色标签决定最终访问。
- 当服务端确认 `OPERATION_ADMIN` 或 `SYSTEM_ADMIN` 时，设置面板在同一位置分别显示“运营管理”或“系统管理”入口。二者进入独立后台管理工作台，并使用同一 `qh_user` 与 RBAC 授权链；入口仅反映当前能力清单，不扩大其资源、动作或数据范围。

## 业务快捷入口

| 入口 | 内容 |
|---|---|
| 我发起的 | 草稿、审核中、招募中、已结束的社区活动 |
| 我参与的 | 已申请、已加入、进行中和历史活动 |
| 评论评价 | 当前用户收到和发出的用户评价，可回到对应订单项或社区参与记录 |
| 商城订单 | 待支付、待发货、待收货和售后 |
| 收藏 | 社区内容和商城商品，按类型筛选 |

## 兑换码状态

| 状态 | 页面表现 |
|---|---|
| 可兑换 | 显示确认兑换和权益说明 |
| 已使用 | 显示使用时间和对应账户 |
| 已过期 | 显示有效期和不可使用原因 |
| 不适用 | 说明适用产品、地区或用户条件 |
| 网络失败 | 保留输入内容并允许重试 |

## 隐私与安全

- 账号安全页展示登录设备、密码或验证方式和账号注销入口。
- 隐私页控制位置、推荐个性化、陌生人消息和活动资料可见性。
- 敏感操作需要二次验证；注销账号不可与退出登录混淆。
